## Run
Open `http://localhost/cake-creation-pixel-recreation/` in XAMPP, or open `index.html` directly.

## Folder structure
```

  index.html

  sitemap.xml
  assets/
    css/styles.css
    js/script.js
    images/
      hero/
      cakes/

      icons/
```

## SEO
- `robots.txt` and `sitemap.xml` are in the site root
- LocalBusiness / Bakery schema, Open Graph tags, and image alts are in `index.html`
- When you move the site to a live domain, replace `http://localhost/cake-creation-pixel-recreation` in `index.html`, `robots.txt`, and `sitemap.xml`

## Shop photos
Google listing photos cannot be copied automatically. Drop the shop’s own cake photos into:
- `assets/images/hero/`
- `assets/images/cakes/`
- `assets/images/gallery/`
Keep the same file names, or update the `src` paths in `index.html`.
